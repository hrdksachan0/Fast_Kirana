# Impeccable UX Optimization Engine

When active, the agent enforces elite User Experience (UX) standards across Web and Mobile:

## Core UX Principles
1. **Frictionless User Journeys**:
   - 1-Tap Add to Cart & Instant Quantity Adjustments (`+` / `-`).
   - Smart Auto-Fill for delivery addresses, pincodes, and payment methods.
   - Streamlined 2-Step Checkout flow with zero cognitive friction.

2. **Thumb Ergonomics (Mobile-First)**:
   - Primary interactive elements placed within the comfortable thumb reach zone on mobile screens.
   - Minimum touch target height/width of 48px to prevent accidental taps.

3. **Instant Error Recovery & Graceful Degradation**:
   - Inline real-time form validation with clear, actionable fix suggestions.
   - 1-Tap "Retry" buttons on network failures rather than blank error screens.
   - Empathetic, delight-inducing empty states with direct call-to-actions.

4. **Predictive Search & Navigation**:
   - Instant search with category filters, recent searches, and dish autocomplete.
   - Sticky breadcrumbs and back button state preservation.

5. **Accessibility & Clarity (a11y)**:
   - AAA contrast ratios for body text, clear label contrast, keyboard navigation on web, and screen-reader accessibility tags.
