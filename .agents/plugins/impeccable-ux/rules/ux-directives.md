# UX Directives for Web & Mobile

- **Rule of Least Effort**: Always reduce the number of clicks/taps required for key user goals (ordering, searching, changing address, editing cart).
- **Feedback Integrity**: Every user interaction must produce immediate feedback within 100ms (visual state change, haptic pulse, or loading indicator).
- **Graceful Error Handling**: Never expose raw system exceptions to users. Provide human-readable recovery steps.
