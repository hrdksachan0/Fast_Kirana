# Serena Semantic Code Intelligence Guidelines

- **AST & Symbol Navigation**: Prioritize symbol-level structure analysis when navigating or editing TypeScript, Python, and Dart codebases.
- **Zero-Hallucination Model Checking**: Always inspect exact definitions in `prisma/schema.prisma`, FastAPI Pydantic models, and Flutter data models before writing integrations.
- **Cross-Service Consistency**: Maintain exact field names and types between Next.js frontend, FastAPI backend, and Flutter mobile apps.
