# SkillUI: Design System & Token Extraction Engine

SkillUI equips Antigravity with capabilities to extract, synchronize, and enforce design tokens, component architecture, and pixel-perfect UI across Web and Mobile.

## Core Capabilities
1. **Design Token Sync**:
   - Maintains exact alignment between CSS variables (src/app/globals.css), Tailwind config, and Flutter Dart tokens (astkirana_flutter/lib/core/theme/brand_design_system.dart).
   - Ensures unified HSL / Hex color palette, spacing scales, border radii, shadows, and typography tracking across platforms.

2. **Component Translation**:
   - Converts Web React / Tailwind UI patterns (floating sticky bars, pill categories, liquid bottom navs) into 1:1 Flutter widgets with native gestures and spring animations.

3. **Anti-Drift Guard**:
   - Enforces design consistency so UI elements never look generic or mismatch between web storefronts and mobile apps.
