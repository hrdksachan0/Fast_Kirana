# Context7 Operational Rules

- **Multi-Layer File Mapping**: When modifying a component or endpoint, check all 7 context layers (API schema, UI component, page route, type definition, and database model).
- **Persistent Change Memory**: Maintain active knowledge of files edited within the current session to ensure cohesive refactoring.
- **State & Log Integrity**: Inspect empirical command outputs and logs before finalizing any file modifications.
