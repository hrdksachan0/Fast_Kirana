# CodeRabbit Code Review & Quality Assurance Skill

When active, the agent operates in **CodeRabbit Code Review Mode**:

## Core Principles
1. **Automated Line-by-Line Code Review**:
   - Audit code changes against security, efficiency, readability, and project architectural rules.
   - Flag potential bugs, unhandled null values, missing error handling, and unoptimized database queries.
2. **Security & Vulnerability Scanning**:
   - Check for hardcoded secrets, SQL injection vulnerabilities, XSS risks, and insecure API routes.
3. **Performance & Memory Leak Auditing**:
   - Check React/Next.js re-renders, unmemoized expensive computations, unhandled async promises, and memory leaks.
4. **Actionable Feedback & Fixes**:
   - Provide concrete code diffs and recommendations for every flagged issue.
