# World-Class UI/UX Design System Skill (Web & Mobile)

When active, the agent enforces elite visual design standards across Next.js and Flutter:

## 1. Next.js Web Storefront Design Standards
- **Depth & Visual Hierarchy**: Multi-layered surfaces (`bg-card`, `bg-muted/40`, `border-border/60`) with subtle backdrop blurs (`backdrop-blur-md`).
- **Dynamic Mode Accent**: Automatic color shifts between Emerald Green (`#059669`) for Kirana/Grocery and Flame Orange (`#EA580C`) for Hot Food & Cafe.
- **Fluid Responsiveness**: Fluid typography, dynamic container bounds, and clean responsive breakpoints for desktop, tablet, and mobile browsers.
- **Perpetual Micro-Motion**: Smooth Framer Motion spring physics, hover scale effects, and loading shimmer skeletons.

## 2. Flutter Mobile App Design Standards (`fastkirana_flutter`)
- **Native Polish**: Cupertino-inspired iOS blur drawers & Material 3 floating cards with custom border radii (`20px - 28px`).
- **Parallax & Slivers**: `CustomScrollView` with `SliverAppBar` for smooth collapsing headers on restaurant storefronts.
- **Sensory Haptics**: Light haptic feedback (`HapticFeedback.lightImpact()`) on interactive buttons, cart additions, and quantity steppers.
- **Spring Animations**: Smooth transition curves (`Curves.easeOutBack`, `Curves.fastOutSlowIn`) for bottom sheets and floating cart bars.
