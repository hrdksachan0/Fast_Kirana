# World-Class UI/UX Guidelines for Next.js & Flutter

- **Design Precision**: Never build generic MVP UI layouts. Every component, button hover, error toast, and loading state must be meticulously designed.
- **Haptics & Touch**: Enable tactile haptic feedback on mobile touch targets.
- **Color Discipline**: Enforce strict palette mapping (Kirana = Emerald Green, Food = Flame Orange, Console = Velvet Red).
- **Typography Standards**: High legibility, crisp letter-spacing (tracking), and tight line-heights across Web and Mobile views.
